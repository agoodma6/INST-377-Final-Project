Project Problem

UMD students and organizations often plan outdoor events without knowing what the weather was like in the past. This project helps users look up historical weather information for planning.

Stakeholders

  • UMD students
  • Student organizations
  • Outdoor event planners
  • Sports clubs

How The Project Helps

Users can search by latitude, longitude, and date. The app shows historical temperature data, displays it on a chart, places the location on a map, and lets the user save useful days.

APIs and Libraries Used

  • Open-Meteo API for historical weather data
  • Supabase for saved weather days
  • Leaflet for the map
  • Chart.js for the chart
